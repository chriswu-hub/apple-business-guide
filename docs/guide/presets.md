# 加入藍圖與配置設定

本單元探討 Apple 商務中「藍圖」的核心架構、企業關鍵安全性與網路設定，以及 Microsoft 365 混合環境的黃金組態範本。

---

### 🎯 學習目標
- 能建立和管理藍圖
- 能設定企業安全性所需的關鍵組態
- **能為 M365 環境設定 Wi-Fi、VPN、憑證**
- 理解各設定對使用者體驗的影響

---

## 6.1 藍圖 (Blueprints) 概念

在 Apple 商務與原生裝置管理中，**藍圖 (Blueprints)** 是將「應用程式」與「各項組態設定」打包在一起的容器：

- **藍圖 = App + 組態設定的組合包**。
- **指派對象彈性**：可直接指派給個別使用者、使用者群組（如業務部、研發部），或是依裝置序號指派。
- **一次設定，全面部署**：IT 人員只需維護藍圖範本，新裝置加入時自動繼承所有設定。
- **動態即時同步**：後續在後台變更藍圖內容（例如更新 Wi-Fi 密碼或新增 App），所有已綁定該藍圖的受管裝置會**在背景自動套用更新**。

## 6.2 關鍵設定項目

### 🛡️ 1. 安全性設定（必要基準線）

| 設定項目 | 用途說明 | 企業建議值 |
| :--- | :--- | :--- |
| **密碼和螢幕解鎖** | 強制密碼複雜度、長度與閒置鎖定時間 | 最少 8 位數，包含英文字母與數字，閒置 5 分鐘自動鎖定螢幕 |
| **檔案保險箱 (FileVault)** | 全磁碟 XTS-AES 256 加密保護 | **強制啟用**，並自動將個人修復密鑰 (PRK) 託管至管理伺服器 |
| **應用程式層防火牆** | 阻擋未經授權的連入連線與網路探測 | **啟用**，僅允許已簽署的合法軟體接收連入連線 |
| **門禁 (Gatekeeper)** | 限制 Mac 應用程式的安裝與執行來源 | **App Store + 已識別開發者 (Identified Developers)** |
| **軟體更新 (DDM)** | 控制 macOS 系統升級與強制重啟時間 | 設定延遲 3-7 天（避免零日相容問題）並指定 14 天內強制重啟安裝 |

---

### 🌐 2. 網路設定

| 設定項目 | 用途說明 | 實務配置重點 |
| :--- | :--- | :--- |
| **Wi-Fi** | 企業無線網路自動連線（802.1X EAP-TLS / PEAP） | 預先配置 SSID 與安全協定，使用者進公司即可秒連內網 |
| **VPN** | 企業虛擬私人網路連線（IKEv2 / IPSec / 隨選 VPN） | 設定 On-Demand VPN，當存取公司內網域名時自動無感建立連線 |
| **憑證 (Certificates)** | 部署企業內部根憑證 (Root CA) 與使用者數位身分 | 用於 802.1X Wi-Fi、內部網站 HTTPS 與 S/MIME 電子郵件加密 |
| **網頁過濾器 (Web Filter)** | 限制特定惡意或違規網站的存取 | 內建 Content Filtering 或搭配 Cisco Umbrella 等安全防護 |

---

### ⚙️ 3. 企業管理與權限控制

| 設定項目 | 用途說明 | 實務配置重點 |
| :--- | :--- | :--- |
| **AirDrop** | 限制 AirDrop 傳輸範圍，防止企業資料外洩 | 限制僅能與「聯絡人」分享，或在特定高資安部門完全禁用 |
| **iCloud** | 控制 iCloud 同步項目與雲端備份 | 僅允許管理式 Apple 帳號同步公務 iCloud Drive，阻斷個人 iCloud |
| **App 存取權限** | 限制或允許特定系統內建 App (如 App Store, Game Center) | 允許透過 MDM 分發 App，限制使用者隨意安裝未經評估之 App |
| **資料管理 (Managed Open In)** | 控制公務資料在 App 之間的分享流向 | 禁止將公務郵件附件透過非受管之個人 App 開啟 |
| **鎖定畫面** | 自訂 Mac 鎖定畫面上的資產標籤與聯絡資訊 | 顯示 *「[公司名稱] 資產，拾獲請聯繫 it@company.com」* |

## 6.3 M365 環境常見設定組合

針對以 Microsoft 365 為核心辦公生態系之企業，推薦採用的**標準商務 Mac 最佳實踐藍圖**：

```
藍圖：「商務部門-Mac」
├── 🛡️ 安全性
│   ├── FileVault：強制啟用，託管復原金鑰 (PRK)
│   ├── 防火牆：啟用
│   ├── 密碼原則：最少 8 位數、含英數字、閒置 5 分鐘鎖定
│   └── 軟體更新：延遲 3 天、強制 14 天內完成安裝
├── 🌐 網路
│   ├── Wi-Fi：自動連線 802.1X 企業無線網路
│   ├── VPN：自動按需連線 (On-Demand) 至企業 VPN
│   └── 憑證：自動派送企業內部 CA 根憑證
├── ⚙️ 管理
│   ├── iCloud：僅允許管理式帳號 iCloud Drive（公私資料隔離）
│   ├── AirDrop：僅限「聯絡人」
│   └── App 存取：允許企業指派之 App Store 軟體
└── 📦 應用程式 (Apps)
    ├── Microsoft 365 套件 (Word, Excel, PowerPoint, Outlook)
    ├── Microsoft Teams
    ├── 公司專屬自訂 App / 資安防護 Agent
    └── Apple 商務 App（背景自動靜默安裝）
```
