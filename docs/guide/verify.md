# 實作檢核與結訓認證

恭喜你完成了 Apple Business、自動裝置註冊 (ADE) 與 MDM 安全管理的完整學習！

在取得結訓認證前，請進行最後的實作成果檢核。

請在已受 MDM 管理的裝置上開啟瀏覽器，或在終端機中確認連線至以下培訓驗證伺服器：

```
http://mdm.idv.tw
```
